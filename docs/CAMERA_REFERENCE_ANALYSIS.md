# VHS Master — Camera Reference Analysis

This document catalogs the visual characteristics, color signatures, and algorithmic implementations for all 7 camera profiles in **VHS Master**.

---

## Profile Catalogue

### 1. Fxc6 Reference Profile
* **Source Reference:** `references/VHS MASTER/Vhs cams_/Fxc6/`
* **Visual Characteristics:** Balanced broadcast relay aesthetic, warm highlight lift, muted green channel response, and subtle RF edge blur.
* **Color Science:** Red Gain: 1.04, Green Gain: 0.99, Blue Gain: 0.96, Warmth Bias: +0.03.

### 2. Gen 7 Reference Profile
* **Source Reference:** `references/VHS MASTER/Vhs cams_/Gen 7/`
* **Visual Characteristics:** Heavy generational tape dub emulation with lifted shadow pedestal (+15 luma), reduced dynamic contrast, and luma bandwidth compression.
* **Color Science:** Red Gain: 0.98, Green Gain: 1.02, Blue Gain: 1.03, Shadow Lift: +0.04.

### 3. JVC GR-C7U (1986)
* **Source Reference:** `references/VHS MASTER/Vhs cams_/Jvc gr-c7u ( 1986)/`
* **Visual Characteristics:** Classic Saticon pickup tube camcorder. Exhibits strong highlight bloom shoulder, high warm saturation, and optical tube grain.
* **Color Science:** Red Gain: 1.12, Green Gain: 1.03, Blue Gain: 0.92, Warmth Bias: +0.06, Rolloff: 80%.

### 4. VHS-R20 Reference Profile
* **Source Reference:** `references/VHS MASTER/retro vhs/`
* **Visual Characteristics:** Standard consumer home VCR SP mode with characteristic horizontal luma softness and trailing edge response.
* **Color Science:** Red Gain: 1.01, Green Gain: 1.00, Blue Gain: 0.98.

### 5. Fall-78 Reference Profile
* **Source Reference:** `references/VHS MASTER/retro vhs/`
* **Visual Characteristics:** Late 1970s color film transfer aesthetic with golden amber highlights and teal-biased shadows.
* **Color Science:** Red Gain: 1.15, Green Gain: 0.96, Blue Gain: 0.90, Warmth Bias: +0.08.

### 6. ERC-V2S Reference Profile
* **Source Reference:** `references/VHS MASTER/plugin work/`
* **Visual Characteristics:** Professional Betacam / U-matic SP emulation with neutral color fidelity and accurate studio pedestal.
* **Color Science:** Red Gain: 1.00, Green Gain: 1.00, Blue Gain: 1.01.

### 7. JVC GR-SXM740U Profile
* **Source Reference:** `references/VHS MASTER/Vhs cams_/`
* **Visual Characteristics:** Super VHS-C camcorder profile with expanded luma bandwidth, crisp edge response, and controlled shadow floor.
* **Color Science:** Red Gain: 1.02, Green Gain: 0.99, Blue Gain: 1.00, Bandwidth: 90%.
